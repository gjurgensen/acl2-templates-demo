# ACL2 templates demo

This repository shows the issue and pull request templates proposed for
[acl2/acl2](https://github.com/acl2/acl2). GitHub uses templates only from a
repository's default branch, so this repository lets you try them before they
are merged.

Feel free to open test issues and pull requests here.

- **Issues:** open the
  [template chooser](https://github.com/gjurgensen/acl2-templates-demo/issues/new/choose)
  and try the bug report and feature request forms.
- **Pull requests:** open a
  [pull request from the `try-pr-template` branch](https://github.com/gjurgensen/acl2-templates-demo/compare/main...try-pr-template?expand=1)
  to see the template in the description box.

The templates are in [`.github/`](.github).
